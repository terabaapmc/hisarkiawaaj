⚙️ Supabase Integration & System Settings

Configure and test your Supabase PostgreSQL database, Authentication, and Storage bucket.

🛡️ Administrator Setup & Security Checklist

1. Database Migrations: Run schema.sql in your Supabase SQL Editor to create tables, indexes, storage bucket, and strict RLS policies.

2. Create Your Admin User: Go to Supabase Dashboard → Authentication → Users → Add User (Email & Password).

3. Grant Administrator Role: In Supabase SQL Editor, run:
SELECT public.promote_to_admin('your-email@example.com');

4. Storage Bucket: The news-media bucket is automatically configured as public for reading images, while writes/deletes are strictly restricted to admins.
